# Prompt Matrix Template

Five prompt intents per category. Write them the way a buyer types or speaks — no brand names.

| # | Intent | Template | Example (travel) |
|---|---|---|---|
| 1 | Category head | "best [category] for [audience]" | best app to book cheap flights in India |
| 2 | Use case | "which [category] is good for [specific need]" | which insurer covers pre-existing diseases early |
| 3 | Comparison | "[option type A] vs [option type B] — which is better for [need]" | term insurance vs money-back policy for a 30-year-old |
| 4 | Price-led | "cheapest / best value [category] with [must-have feature]" | best value phone insurance with quick claims |
| 5 | Problem-led | "[category] that solves [pain point]" | mattress for back pain under a fixed budget |

Rules:

- Freeze the matrix before running; changes wait for the next cycle.
- Keep the buyer's words, not the brand's marketing words.
- One intent per prompt; compound questions produce unscoreable answers.
